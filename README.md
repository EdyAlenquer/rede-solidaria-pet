# Rede Solidária Pet

Projeto com foco na análise e organização de uma solução web para apoio a animais em situação de rua.

## Objetivo

Propor uma plataforma web simples para centralizar pedidos de ajuda e doações.

## Setor de aplicação

Comunidade local, protetores independentes e ONGs de proteção animal.

## ODS

- ODS 3 – Saúde e Bem-estar
- ODS 11 – Cidades e Comunidades Sustentáveis
- ODS 15 – Vida Terrestre

## Artefatos

- Diagrama de atividades
- Diagramas de classes
- Requisitos funcionais
- Requisitos não funcionais
- Checklist de auditoria de configuração
