# Requisitos Não Funcionais

| Código | Requisito Não Funcional                                |
| ------ | ------------------------------------------------------ |
| RNF01  | O sistema deve ter interface simples e intuitiva       |
| RNF02  | O sistema deve ser responsivo para celular             |
| RNF03  | O sistema deve ter bom contraste e legibilidade        |
| RNF04  | O sistema deve preservar a privacidade dos dados       |
| RNF05  | O sistema deve ter navegação com poucos passos         |
| RNF06  | O sistema deve carregar adequadamente em rede móvel    |
| RNF07  | O sistema deve ser compatível com navegadores modernos |
| RNF08  | O sistema deve usar linguagem clara e acessível        |
